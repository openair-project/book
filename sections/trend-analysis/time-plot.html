11  Time series plots

11.1 Background

The timePlot() function is designed to quickly plot time series of data, perhaps for several pollutants or variables. This is, or should be, a very common task in the analysis of air pollution. In doing so, it is helpful to be able to plot several pollutants at the same time (and maybe other variables) and quickly choose the time periods of interest.

With packages such as ggplot2 it is very easy to plot time series. However, there are a few enhancements in timePlot() that are useful for the analysis of air quality data including:

  • The ability to flexibly time average the data in several ways e.g., to plot daily or monthly means from hourly data, or hourly means from 15-minute data.
  • The ability to plot multiple sites and pollutants in separate panels or grouped together in one panel using the type and group arguments.
  • The ability to normalise data to a common scale of 100 at the start of time series, which is useful for comparing time series on different scales e.g., emissions and ambient measurements.
  • The ability to plot wind vectors on time series plots, which is useful for understanding the relationship between pollution and wind speed/direction.
  • Automatic formatting of common pollutant names and units.

The function offers fine control over many of the plot settings such as line type, colour and width. If more than one pollutant is selected, then the time series are shown compactly in different panels with different scales. Sometimes it is useful to get an idea of whether different variables ‘go up and down’ together. Such comparisons in timePlot() are made easy by setting group = TRUE, and maybe also normalise = "mean". The latter setting divides each variable by its mean value, thus enabling several variables to be plotted together using the same scale. The normalise option will also take a date as a string (in British format dd/mm/YYYY), in which case all data are normalised to equal 100 at that time. Normalising data like this makes it easy to compare time series on different scales e.g., emissions and ambient measurements.

timePlot() works very well in conjunction with selectByDate(), which makes it easy to select specific time series intervals. See Section 27.1 for examples of how to select parts of a data frame based on the date.

Another useful feature of timePlot() is the ability to average the data in several ways. This makes it easy, for example, to plot daily or monthly means from hourly data, or hourly means from 15-minute data. See the option avg.time for more details and Section 27.4 where a full description of time averaging of data frames is given.

11.2 Examples of time series plotting

A full set of examples is shown in the help pages — see ?timePlot for details. At the basic level, concentrations are shown using a simple call e.g., to plot time series of NOx and O3 in separate panels with their own scales.

timePlot(
  mydata,
  pollutant = c("nox", "o3"),
  scales = "free_y"
)

Often it is necessary to only consider part of a time series and using the openair function selectByDate() makes it easy to do this. Some examples are shown below.

To plot data only for 2003:

timePlot(
  selectByDate(mydata, year = 2003),
  pollutant = c("nox", "o3"),
  scales = "free_y"
)

Plots for several pollutants for August 2003 are shown in Figure 11.1.

library(openair)
library(tidyverse)

timePlot(
  selectByDate(mydata, year = 2003, month = "aug"),
  pollutant = c("nox", "o3", "pm25", "pm10", "ws"),
  strip.position = "right",
  scales = "free_y"
)

Some other examples (not plotted) are:

## plot monthly means of ozone and no2
timePlot(
  mydata,
  pollutant = c("o3", "no2"),
  avg.time = "month",
  scales = "free_y"
)

## plot 95th percentile monthly concentrations
timePlot(
  mydata,
  pollutant = c("o3", "no2"),
  avg.time = "month",
  statistic = "percentile",
  percentile = 95,
  scales = "free_y"
)

## plot the number of valid records in each 2-week period
timePlot(
  mydata,
  pollutant = c("o3", "no2"),
  avg.time = "2 week",
  statistic = "frequency",
  scales = "free_y"
)

An example of normalising data is shown in Figure 11.2. In this plot we have:

  • Averaged the data to annual means;

  • Chosen to normalise to the beginning of 1998;

  • Set the line width to 2 and the line type to 1 (continuous line);

  • Chosen to group the data in one panel.

Figure 11.2 shows that concentrations of NO2 have increased over the period 1998–2005; CO and SO2 have shown the greatest reductions (by about 50–60%), whereas NOx concentrations have decreased by about 25% and PM10 shows little overall change.

timePlot(
  mydata,
  pollutant = c("nox", "no2", "co", "so2", "pm10"),
  avg.time = "year",
  normalise = "1/1/1998",
  linewidth = 2,
  linetype = 1,
  lineend = "round",
  group = TRUE,
  ylim = c(0, 125)
)

Another example is grouping pollutants from several sites on one plot. It is easy to import data from several sites and to plot the data in separate panels e.g.,

## import data from 3 sites
aq <- importUKAQ(
  site = c("kc1", "my1", "nott"),
  year = 2005:2010
)

## plot it
timePlot(
  aq,
  pollutant = "nox",
  type = "site",
  avg.time = "month"
)

In Figure 11.3 the y-scale is the same by default for all panels. However, the y-scales can be set individually for each panel by setting scales = "free_y". Other options include scales = "free_x" for individual x-axis scales and scales = "free" for this to apply to both the x- and y-axes.

Using the code above it is also possible to include several species. But what if we wanted to plot NOx concentrations across all sites in one panel? An example of how to do this is shown below. In this case the group argument is used to display the concentrations from multiple sites in one panel.

timePlot(
  aq,
  pollutant = "nox",
  group = "site",
  avg.time = "month",
  linetype = 1,
  cols = "tol.bright",
  linewidth = c(1.5, 1, 0.7),
  ylab = "nox (ug/m3)"
)

If wind speed ws and wind direction wd are available they can be used in plots and shown as ‘wind vectors’. Plotting data in this way conveys more information in an easy-to-understand way, which works best for relatively short time periods e.g., a pollution episode lasting a few days. As an example Figure 11.5 shows the first 48 hours of NOx and NO2 data with wind arrows shown. The appearance of the arrows (e.g., their length range, arrowhead, colour and line width) is controlled using windflowOpts(). Wind vector arrows can also be used with the scatterPlot() function.

See help for windflowOpts() for more details on the options available to control the wind vectors.

timePlot(
  head(mydata, 48),
  pollutant = c("nox", "no2"),
  windflow = windflowOpts(
    linewidth = 0.6,
    colour = "skyblue"
  ),
  strip.position = "right",
  linewidth = 2,
  cols = "tol.bright",
  key.position = "none",
  scales = "free_y",
  ylab = "concentration (ppb)"
)
